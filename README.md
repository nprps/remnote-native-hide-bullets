# WITHDRAWN — Native Hide Bullets Everywhere

The author withdraws this plugin from RemNote marketplace consideration. Please do not approve or publish the pending submission.

The native-setting helper has been retired in favor of CSS that hides only parent-row markers without changing layout. The local development plugins have been uninstalled, their local servers stopped, and GitHub Pages hosting disabled.

Do not install the packages in this repository. They are retained only as an implementation record, not an active or supported plugin. This notice expresses the author's withdrawal; it is not confirmation that RemNote has processed the pending review cancellation.
